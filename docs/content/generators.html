CLI: bb new

bb new <type> [name] creates one feature: behavior JSON, resource JSON, plus the texture and lang entries. It writes every linked file or nothing on conflict. 

bb new weapon fire_sword --mode 3d --icon sword
bb new block glow_block --light 12
bb new recipe steel_ingot --recipe-kind furnace --result steel_ingot
bb new item ruby --from ./sword.json

--from imports the behavior body from an existing json file instead of generating one. Registries, lang entries, and sidecars are still wired from the flags. Identifiers in the imported file move into the project namespace. The file must share a top-level key with the generated behavior file, like minecraft:item.

Types

weapon, tool, armor, item, entity, block, recipe, loot, spawn, trade, dialogue, animation, equipment, feature, feature_rule, particle, fog, function, voxel_shape, biome, camera, item_catalog, sound, biomes_client, block_culling, dimension, ui, loot_table.

Common flags

Flag Description
--name <name> Override for the positional name.
--icon <name> Icon name and texture key.
--display-name <s> Display name override.
--mode <2d|3d|icon> Render mode. Weapon and entity take 2d or 3d. Armor takes icon or 3d.
--geometry <id> 3D geometry id from an imported model.
--texture <path> 3D texture path or block texture key.
--from <file> Import the behavior body from a json file.
--spawn-egg Write a spawn egg item for the entity.
--force Overwrite conflicting files.
--dry-run Print the plan, write nothing.
-y, --yes Accept defaults, non-interactive.

Items and blocks

Flag Description
--variant <type> Tool: pickaxe, axe, shovel, hoe.
--piece <type> Armor: helmet, chestplate, leggings, boots.
--tier <tier> Tool tier. Default is diamond.
--durability <n> Item durability.
--damage <n> Weapon and tool damage.
--protection <n> Armor protection.
--enchant-value <n> Enchantability value.
--repair-item <id> Repair item identifier.
--sound <sound> Block sound. Default is stone.
--render-method <m> Block render method: opaque, blend, alpha_test.
--light <0-15> Block light emission.
--recipe <kind> Also write a recipe: shapeless or furnace.
--loot <kind> Also write a loot table: entity, block, or chest.

Recipes and loot

Flag Description
--recipe-kind <k> Recipe: shapeless, shaped, furnace.
--pattern <rows> Shaped rows, semicolon separated.
--key <map> Shaped symbols, X=id comma separated.
--result <id> Recipe output or loot drop id.
--ingredients <ids> Recipe inputs, comma separated.
--count <n> Recipe output count.
--loot-kind <k> Loot: entity, block, chest.
--rolls <n> Loot pool rolls.
--min <n> Loot drop min count.
--max <n> Loot drop max count.
--unlock <id> Recipe unlock item id or context:name. Defaults to the first ingredient.
--pools <n> Loot table pool count, 1 to 16. Default is 3.
--max-uses <n> Trade max uses.
--xp <n> Trade xp reward.

Entities and world

Flag Description
--spawn-category <k> Spawn: animal, monster, ambient, water.
--weight <n> Spawn weight.
--equipment <kind> Also write an equipment table for the entity.
--animation <id> Animation to play.
--want <id> Trade want id.
--give <id> Trade give id.
--dialogue-text <s> NPC line.
--dialogue-button <s> NPC button.
--color <hex> Fog or biome water color.
--fog <id> Biome fog identifier.
--category <c> Item catalog category.
--group <id> Item catalog group.
--command <text> Function command line.
--sound-file <path> Sound file path.
--direction <dir> Culling direction.
--x <n>, --y <n>, --z <n> Camera position.

Safety

Generators plan every file before writing. Existing files with different content are conflicts. The generator stops and writes nothing unless --force is set. --dry-run prints the create, update, and skip list.
