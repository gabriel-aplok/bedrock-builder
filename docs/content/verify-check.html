Verify with bb check

bb check inspects the project and lists what is missing. Run it after create, after cloning, and before shipping. 

bb check
bb check --fix
bb check --json

What it checks

  • Config loads: name plus version present, semver valid.
  • Both pack dirs exist on disk.
  • Both manifest.json files exist.
  • Entry file exists at bb.entry.
  • Deploy target resolves to a real com.mojang folder.
  • Extension tools on PATH when enabled. Warns only, never fails. Audio copies through without it.

Fix mode

--fix loads the config leniently, so it runs on broken projects too. It creates missing pack dirs, writes minimal manifests with fresh UUIDs, and creates the entry file. It prints how many items it fixed. Rerun bb check after to confirm green.

CI use

Exit code is 0 when every check passes, 1 on any failure. --json prints one report object with a checks array. Parse stdout, never stderr.
