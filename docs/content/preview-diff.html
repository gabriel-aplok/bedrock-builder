Preview changes with bb diff

bb diff shows what changed since the last build. It reads the existing cache, compares hashes, and lists added, modified, and deleted files. It never builds and never writes. 

bb diff
bb diff --json

What each status means

  • Added: source exists with no cache entry. It ships on the next build.
  • Modified: hash differs from the last build, or the output is missing.
  • Deleted: cache entry exists but the source is gone. The next build prunes the output.

When the cache is empty

With no cache file every source lists as added. Run bb build once, then bb diff reports only real changes. bb clean wipes the cache, so diff after clean lists everything as added.
