Release with bb publish

bb publish runs the full release flow in one command: optional version bump, ship, harness, git tag, git push. 

bb publish --dry-run
bb publish --bump minor --tag --push

Step order

  • Bump first when --bump is set. Accepts patch, minor, major, or x.y.z. Writes to config plus both manifests.
  • Ship a release build into dist/<name>-<version>.mcaddon.
  • Harness the output. Any finding stops the release with exit code 12.
  • Tag v<version> when --tag is set. Fails when git tag fails.
  • Push plus push tags when --push is set. Fails when either push fails.

Preview first

--dry-run prints the plan and runs nothing: the ship target, the harness step, the tag name, the push steps. Use it before every real publish.

Typecheck option

--typecheck runs tsc --noEmit before shipping. Diagnostics print with file, line, column, and code. Exit code is 6.
