Hot Reload Setup

bb run --watch builds the project, copies the result into the game dev pack folders, and rebuilds on every save. Reload the world to see updates. 

bb run --watch

How it works

  • First run is a full build plus a clean copy into development_behavior_packs/<name>/ and development_resource_packs/<name>/.
  • Saves batch at 100ms. One log line per batch, not per file.
  • Temp files are ignored. Only pack and source changes trigger rebuilds.
  • Type errors print through a parallel tsc --watch and never block the rebuild. Pass --no-types to turn that off.

Retail deploy targets

On Windows the retail target checks the Bedrock launcher, the Preview launcher, the Store build, the Store beta, and both Education installs. On macOS and Linux it checks the mcpelauncher homes. When no install is found the command exits with code 3 and lists every path it checked.

One shot run

bb run
bb run --release

Without --watch the command builds once and copies once, then exits. Use --release for a final playtest on minified output.
