Changelog

Release history for Bedrock Builder.

0.1.0 - first release

  • Create projects with bb init and generate resources with bb new.
  • Bundle scripts, copy both packs, deploy locally, and watch for changes.
  • Validate projects with bb check and bb harness.
  • Create release builds and .mcaddon files with bb ship.
  • Support project-enabled extensions and JSON output for scripts and CI.
  • Provide a JavaScript and TypeScript API.
