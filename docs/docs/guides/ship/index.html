Shipping a .mcaddon

bb ship runs a release build, validates both manifests, and zips the packs into one shareable file. 

bb ship
$ bb ship --output ./releases/my-addon.mcaddon --level 9

What ship does

  • Runs a release build first. There is no dev mode pack.
  • Validates both manifests: required fields, real UUIDs, engine version, and the RP to BP link. Failures stop the zip with exit code 4.
  • Zips dist/packs/BP/ as <name>_BP/ and dist/packs/RP/ as <name>_RP/ inside the archive.
  • Default output is dist/<name>-<version>.mcaddon.
  • Default compression is 6. --level 0 stores raw, --level 9 compresses hardest.

Publish flow

bb publish --bump minor --tag --push

bb publish optionally bumps the version first, then ships, harnesses, tags, and pushes. --dry-run prints the plan and runs nothing. --typecheck runs tsc --noEmit before shipping.

Verify before shipping

bb check
$ bb harness

bb check verifies the project. bb harness builds and cross-checks every icon, texture, recipe, and spawn reference in dist/. Ship both green before sharing.
