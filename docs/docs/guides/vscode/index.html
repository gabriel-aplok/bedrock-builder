VS Code Extension

The Bedrock Builder extension runs bb commands from the command palette, wires Mojang schemas into json files through user settings (no project files), and adds go to definition for identifiers, geometry, and file refs. Script hover and go to come from the TypeScript server once the project resolves.

Install

cd bedrock-vscode
$ npm install
$ npm run build
$ npm run vsix

Install the vsix with Extensions: Install from VSIX, or run with F5 from bedrock-vscode/.

Commands

Command Description
Bedrock: Build Bundle scripts and copy packs to dist/.
Bedrock: Run in game Deploy, using the bedrock.run.world target when set.
Bedrock: Select run world Pick the deploy world from installed worlds, or clear back to dev packs.
Bedrock: Ship .mcaddon Release build plus .mcaddon zip.
Bedrock: Compile brarchive pack Server-optimized pack via the dedicated server.
Bedrock: Select server folder Pick the folder holding bedrock_server.exe.
Bedrock: Check project Run bb check, findings land in the Bedrock channel.
Bedrock: Check scripts Runtime imports, BP manifest dependency, and installed server major.
Bedrock: Test content links Run the harness, findings land in the Bedrock channel.
Bedrock: Pack report Read-only pack health: counts, duplicates, big files.
Bedrock: New feature Type pick, name input, and sidecar kind picks.
Bedrock: Show changed files List changed files since the last build in the Bedrock channel.
Bedrock: Rewrite manifests Sync pack manifests, with an optional version for both packs.
Bedrock: Bump version Set the project version in config plus both manifests.
Bedrock: Publish release Ship, harness check, and optional version bump, tag, and push.
Bedrock: Import pack folder Adopt the open folder with generated config and package files.
Bedrock: New project Scaffold a project into a picked parent folder, then offer to open it.
Bedrock: Update dependencies Refresh @minecraft/server and the builder.
Bedrock: Start watch deploy Deploy watch with stop control, backed by startDeployWatch.
Bedrock: Refresh completions Rebuild the project value index for json completion.
Bedrock: Select schema version Pick the Mojang schema version from latest, beta, or exact.

Settings

Setting Description
bedrock.configPath Config path relative to the workspace folder. Empty means auto detect.
bedrock.run.world Deploy into a named world folder. Empty means the dev packs.
bedrock.brarchive.serverDir Folder with bedrock_server.exe. Empty means config, env, then local.
bedrock.harness.strict Strict harness: unused lang keys and missing icons fail.
bedrock.schema.version Mojang schema version: latest, beta, or exact.
bedrock.schema.auto Download schemas and wire json validation on startup.
bedrock.script.check Check script setup on startup.
