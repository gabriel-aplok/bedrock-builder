Bedrock Builder documentation

Bedrock Builder is a build tool for Minecraft Bedrock add-ons. One binary, called bb, creates the project, generates features, bundles scripts, deploys into the game, and ships the release zip.

Output is standard behavior and resource pack folders. Other tools can read them. No proprietary project format, no lock-in.

Start here

Getting Started creates a project, builds it, hot reloads it into Minecraft, and ships a .mcaddon. Five minutes, four commands.

bb new writes every linked file for a feature in one command. 28 types, from weapons to dimensions.

How the docs are organized

  • Concepts explain the workspace layout, the packs, and the build pipeline.
  • Guides cover hot reload, shipping, and custom deploy paths.
  • Reference lists every command, every generator flag, the config schema, and the exit codes.

At a glance

  • 14 commands: init, build, watch, run, ship, clean, folders, ext, check, new, manifest, version, harness, publish.
  • 28 generators under bb new. Each writes all linked files or nothing on conflict.
  • Runs on Node 20.19 or later, on Windows, macOS, and Linux.
